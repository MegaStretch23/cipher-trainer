Classical Cipher Trainer

Paste a ciphertext, pick a cipher (or auto) and read the cryptanalysis as it happens: letter-frequency tables, the Vigenere key-length guess from Kasiski distances and the index of coincidence, chi-squared scores for each shift, and the quadgram score of every hill-climb restart. Use it to learn how these ciphers fall, or to check a puzzle.

Private by construction. Everything runs in this page. The page code makes no network calls and the text you paste never leaves your browser tab. Breaking is statistical: a short ciphertext can come out wrong, and the trace shows the scores so you can judge the result.

What each break does

  • Caesar: try all 26 shifts and keep the one whose letter counts are closest to English (chi-squared).
  • Atbash: no key; the alphabet is reversed.
  • Vigenere: Kasiski (repeated trigram distances) and the index of coincidence for each key length pick the length; then each column is a Caesar shift, solved by chi-squared.
  • Simple substitution: start from frequency ranks, then hill-climb: swap two letters of the key, keep it if the English quadgram score rises, restart from the best key a few times.
  • Columnar transposition: for each width, search the column order with the same quadgram score; the highest-scoring width wins.

English statistics come from public-domain Project Gutenberg texts. The same code ships as a stdlib Python CLI, cipher_trainer.py (with data.json): python3 -I cipher_trainer.py break auto -f message.txt. Not covered: ciphers with spaces or punctuation kept in the key, nulls, digraph and machine ciphers, and non-English text.
